# Software

Arduino (C++) code for the ESP32.

- `LaunchCode` — flight software: sensor reading, state machine, microSD logging, recovery trigger
- `The other files` : test sketches for each component (BMP280, MPU6050, microSD, LEDs, buzzer, MOSFET, reset button)

Libraries: Adafruit_Sensor, Adafruit_BMP280, Adafruit_MPU6050.
